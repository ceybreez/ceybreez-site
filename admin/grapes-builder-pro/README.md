# CEYBREEZ Builder Pro v1

A standalone GrapesJS-based visual builder for:

1. Welcome Page
2. Home
3. Villas
4. Apartments
5. Homestays
6. Tours
7. Services
8. Tour Package Details
9. Contact

## Install

Copy this folder into your project:

`admin/grapes-builder-pro/`

Then open:

`https://your-domain.com/admin/grapes-builder-pro/`

## Included now

- Drag and drop blocks
- Element selection and inline editing
- Style Manager
- Layers Manager
- Trait/Settings Manager
- Desktop / Tablet / Mobile views
- Undo / Redo
- 30-second autosave
- Browser draft storage
- Preview
- Export ZIP
- Protected dynamic block placeholders
- Tour detail dynamic placeholders
- Attempted publish to `/api/admin/page-builder/publish`

## Important

The builder can be used immediately for designing and exporting. Direct live publishing requires the Worker route described in `worker-route-example.js` and a matching D1 table.

Do not replace the live public pages until you have previewed the exported pages.
