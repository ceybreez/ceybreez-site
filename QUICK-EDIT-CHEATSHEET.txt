CEYBREEZ QUICK EDIT CHEAT SHEET
================================

OPEN THE WHOLE WEBSITE FOLDER IN VS CODE
File > Open Folder > choose the repository root.

FAST SEARCH TERMS
- HTML visible section: SECTION:
- CSS visual section: CSS SECTION:
- JavaScript helper/function: JS FUNCTION:
- Hard-coded photo: IMAGE SOURCE:

COMMON EDITS
- Text / headings / button labels -> matching .html file
- Font color -> CSS `color:`
- Background -> CSS `background:` / `background-color:`
- Padding -> CSS `padding:`
- Gap between cards -> CSS `gap:`
- Section height -> CSS `min-height:` / `padding-block:`
- Static photo -> change `<img src="...">` in HTML or `url(...)` in CSS
- CMS photo/data -> edit it in Admin/CMS, not the hard-coded HTML

IMPORTANT FILES
Home: index.html + ceybreez-home-v3.css
Tours: tours.html + tours.css + tours-v4.css
Tour details: tour-details.html + tour-details.css + tour-details-v4.css
Villas: villas.html + villas.css + stays-v4.css + villas-v4.css
Apartments: apartments.html + apartments.css + stays-v4.css + apartments-v4.css
Homestays: homestays.html + homestays.css + stays-v4.css + homestays-v4.css
Services: services.html + services.css + services-v4.css
Contact: contact.html + contact.css + contact-v4.css
Language button: ceybreez-language.css / ceybreez-language.js

DO NOT
- Do not paste V4 CSS over the base CSS. Keep both files.
- Do not remove IDs used by forms/planner/CMS.
- Do not put HTML comments inside an opening tag or class attribute.

DEPLOY
Commit only changed files to GitHub, push, wait for Cloudflare deployment, then Ctrl + F5.
