CeyBreez Security V5.3.2 — Password Recovery

WHAT IS NEW
- Recovery email is required for new Admin users.
- Login page now has "Forgot password?".
- A reset link is emailed to the account's recovery email.
- Reset links expire after 15 minutes and are one-time-use.
- Successful reset revokes all active sessions.
- Super Admin can still reset staff passwords from User Management.
- Emergency Super Admin recovery is available with the Cloudflare ADMIN_TOKEN.
- All reset events are written to the security audit log.
- PBKDF2 remains at 100,000 iterations for Cloudflare Worker compatibility.

DEPLOYMENT ORDER
1. GitHub / Cloudflare Pages:
   Replace only:
   - admin/index.html
   - admin/security-rbac.js
   - admin/css/security-rbac.css
   Then commit/push and allow Pages to deploy.

2. Cloudflare Worker:
   Replace the current Worker source with:
   CeyBreez-Cloudflare-Worker-Security-V5.3.2.js
   Save and Deploy.

3. Keep these Worker secrets/settings:
   - ADMIN_TOKEN (required for approval replay + emergency recovery)
   - RESEND_API_KEY (required to send password reset emails)
   - FROM_EMAIL (recommended; existing CeyBreez email sender can remain)
   - DB binding
   Optional:
   - PUBLIC_SITE_URL=https://ceybreez.com

4. Database:
   No manual SQL is required.
   The Worker automatically adds the admin_users.email column (if missing)
   and creates admin_password_resets.

FIRST SETUP
- First-time Super Admin setup now asks for a Recovery Email.
- If a Super Admin already exists from V5.3/V5.3.1:
  sign in -> User Management -> Edit your Super Admin -> add Recovery Email -> Save.
- If that existing Super Admin password is already forgotten:
  Login -> Forgot password? -> Emergency Super Admin recovery
  and use the current Cloudflare ADMIN_TOKEN.
