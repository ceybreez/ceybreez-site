CEYBREEZ MOBILE HORIZONTAL HEADER V4.14
=======================================

WHAT THIS DOES
- Removes the mobile hamburger/dropdown/drawer visually.
- Keeps the page menu visible inside the header on mobile.
- Swipe the menu row LEFT / RIGHT to reach every page.
- The active page is highlighted in gold and auto-centers when possible.
- Desktop navigation is unchanged.

REPLACE THESE HTML FILES
- index.html
- villas.html
- apartments.html
- homestays.html
- tours.html
- tour-details.html
- services.html
- contact.html
- privacy.html
- terms.html
- 404.html

ADD THESE 2 NEW SHARED FILES TO THE REPOSITORY ROOT
- ceybreez-mobile-header.css
- ceybreez-mobile-header.js

DO NOT DELETE YOUR EXISTING PAGE CSS/JS FILES.
This CSS loads last and only changes the mobile header/navigation behavior.
