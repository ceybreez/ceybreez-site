CEYBREEZ Visual Builder – Stable Selection + Publish Live

1. Replace the four files in admin/grapes-builder/.
2. Log in through the normal Admin Panel first.
3. Open the visual builder and hard refresh with Ctrl + F5.
4. Select any card/image/text element, edit it, then use Save Draft.
5. Save Draft survives builder reload in the same browser.
6. Publish Live writes section element styles, text and image URLs to the existing Page Sections API.
7. Public page-builder.js applies the published Desktop, Tablet and Mobile records.
