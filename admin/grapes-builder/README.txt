CEYBREEZ VISUAL BUILDER - STABLE SELECTION BUILD

Open: /admin/grapes-builder/

Controls:
- Single click or pointer-down selects an element.
- Blue outline, toolbar and resize handles appear.
- Double-click text to edit directly.
- Desktop edits are the base for tablet and mobile.
- Tablet and mobile style changes are stored as device overrides.
- Save Draft stores changes in the current browser.
- Image replacement is saved as a permanent URL after a successful API upload.

This build uses a fresh draft key so old damaged drafts do not interfere.
